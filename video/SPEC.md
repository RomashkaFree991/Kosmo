# Kosmo — промо-ролик для TikTok (спецификация по скиллу `motion-designer`)

## 1. Overview
- **Title:** «Kosmo — мессенджер будущего»
- **Duration:** 40.5 s (1215 кадров)
- **Dimensions:** 1080×1920 (9:16), 30 fps
- **Style:** тёмный космос, стеклянные панели (Liquid Glass), один акцент — фиолетовый `#9C7FEB` (акцент приложения), настоящие экраны Kosmo в телефоне
- **Mood:** уверенный, технологичный, «вау» на смене дизайнов
- **Goal:** показать возможности и привести в Telegram-канал **@KosmoMessenger** (там будет APK)

## 2. Audio strategy
- **Voice-over:** мужской нейроголос ru-RU Dmitry (edge-tts), +6 % темп, −2 Hz; 100 % громкости, таймкоды слов → субтитры
- **Music:** Mixkit «Digital Clouds» (#175, 129 BPM, лицензия Mixkit Free). Дроп песни 29.92 s поставлен на 7.30 s ролика («Два дизайна»). Под голосом музыка приглушена (sidechain ≈ −9 dB), финал — затухание 38–40.5 s
- **SFX (синтез в коде):** whoosh на каждой смене сцены, pop на появлении чипов, мягкий «удар» на дропе и на логотипе, тик на CTA
- **Loudness:** −14 LUFS, true peak −1.5 dB

**Transitions:** телефон — общий элемент между сценами (меняется только экран внутри: сдвиг/шторка), заголовки — masked text rise по словам, выход быстрее входа (3:2).

**Focus:** в каждой сцене одна вещь: заголовок сверху → экран → субтитр.

## 4. Technical
- Remotion 4, `TransitionSeries` не нужен: сцены — `<Sequence>` по таймкодам голоса
- Шрифты: Unbounded (заголовки, кириллица), Inter (субтитры)
- Пружины: UI 320/30, контейнеры/камера 170/26, логотип 120/24 (damping ratio ≥ 0.72)
- Безопасные зоны TikTok: текст в центре, 80 px по бокам, низ (> 1650 px) и правая колонка свободны
- Экраны — настоящие снимки Kosmo (Playwright, 1170×2532), данные демо
