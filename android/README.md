# Kosmo для Android

Нативный клиент Kosmo на **Kotlin + Jetpack Compose** (Material 3, динамические цвета Android 12+).
Никакого WebView: экраны написаны на Compose, данные идут напрямую с сервера Kosmo —
те же REST, WebSocket и патчи синхронизации, что использует сайт (`web/js/api.js`, `web/js/patch.js`).
Поэтому приложение и сайт видят одну и ту же переписку в реальном времени.

## Что есть
- Заставка — та же планета, что на сайте (геометрия SVG 120×120, те же анимации колец).
- Вход и регистрация: почта → код из письма → код-пароль; имя и @username с проверкой занятости.
- Чаты: список с непрочитанными и галочками, личные чаты, «Избранное», группы и каналы, чат Kosmo.
- Сообщения: текст, ответы, правка, удаление, реакции, фото (с подписью), видео, голосовые
  (запись и прослушивание с перемоткой по волне), кружки, стикеры, большие эмодзи, звонки в истории.
  Загрузка видна сразу: само фото / голосовое с кольцом прогресса.
- «Печатает…», «в сети», время последнего визита.
- Звонки голосом и с видео (WebRTC), тот же протокол сигналов, что у сайта: звонить можно
  из приложения на сайт и обратно. STUN/TURN — с сервера (`/api/ice`).
- Профиль как на сайте (баннер, аватар с орбитой, плашки), редактирование: каждое поле — свой экран
  с правилами и галочкой; обрезка фото кругом/рамкой с перетаскиванием и масштабом.
- Чужой профиль: написать, позвонить, видеозвонок, заблокировать.
- Лента: посты, свой пост с фото, реакции, просмотры. Поиск людей по имени, @username и ID.
- Сеансы (завершить чужой), выход.
- Последний снимок данных хранится на телефоне — приложение открывается сразу, без сети.

Пока только на сайте: опросы, списки дел, истории, создание групп и каналов, настройки приватности,
код-пароль на вход в приложение. Такие сообщения в чате показываются подписью.
Push-уведомлений, пока приложение закрыто, нет (нужен Firebase).

## Проверка без телефона
- `SyncTest` — живой тест против локального сервера: регистрация, переписка двух аккаунтов
  через WebSocket, перезагрузка снимка, загрузка файла.
  `KOSMO_TEST_URL=http://127.0.0.1:4010 ./gradlew testDebugUnitTest` (сервер с `TEST_NUMBERS=1`).
- `Screens` — скриншоты экранов (Paparazzi): `./gradlew recordPaparazziDebug`,
  картинки — `app/src/test/snapshots/images/`.

## Сборка
```sh
cd android
echo "sdk.dir=/path/to/android-sdk" > local.properties
KOSMO_KEYSTORE=/path/kosmo-app.keystore KOSMO_KEYSTORE_PASSWORD=... ./gradlew assembleRelease
# другой сервер: ./gradlew assembleRelease -PkosmoUrl=https://example.org
```
Готовый APK кладётся в `web/kosmo.apk` («Профиль → О Kosmo → Download for Android»).
Ключ подписи в репозиторий не коммитится; обновление поверх установленного приложения
работает только с тем же ключом.
