# Kosmo для Android

Нативный клиент Kosmo на **Kotlin + Jetpack Compose** (Material 3, динамические цвета Android 12+).
Никакого WebView: экраны написаны на Compose, данные идут напрямую с сервера Kosmo —
те же REST, WebSocket и патчи синхронизации, что использует сайт (`web/js/api.js`, `web/js/patch.js`).
Поэтому приложение и сайт видят одну и ту же переписку в реальном времени.

## Что есть
- Дизайн как на сайте: **Liquid Glass** и **Material You** (Профиль → Designs), тёмная/светлая/авто тема,
  11 исходных цветов и стили цвета Material (material-kolor — те же алгоритмы, что на сайте).
  Шапки из круглых кнопок и пилюль, плавающая нижняя панель: у стекла «линза» перетекает
  к вкладке на пружине (её можно тащить пальцем), у Material — пилюля с подписью. Обои Material.
- Русский и английский интерфейс — тот же словарь, что у сайта (`assets/ru.json` из `web/js/i18n.js`).
- Заставка — та же планета, что на сайте.
- Вход и регистрация; код-пароль на вход в приложение (Security → Passcode lock, автоблокировка).
- Чаты: папки (Все, Личные, Группы, Каналы, Непрочитанные), закреп, без звука, архив, очистка,
  удаление; меню «+»: новый чат, группа, канал. Группы и каналы: создание, участники, вход/выход.
- Чат: меню ⋮ (поиск по чату, звонки, информация, обои чата, звук, очистка, удаление),
  закреплённое сообщение, ответы, правка, пересылка, реакции, удаление.
  Меню «+»: фото и видео (несколько), код, кружок (CameraX), список дел, опрос/викторина,
  геопозиция, музыка. Эмодзи и стикеры. Голосовые с волной и перемоткой.
  Пузыри всех видов: фото, альбомы, видео, кружки, голосовые, музыка, код, опросы, списки дел,
  геопозиция с картой, пересланные посты, звонки, стикеры, «на один просмотр».
- Звонки голосом и с видео (WebRTC), совместимы с сайтом.
- Лента: истории (просмотр, лайк, ответ), посты с фото и кодом, реакции, комментарии,
  «поделиться» в чат, новый пост. Поиск: чаты и люди, сообщения, медиа.
- Профиль как на сайте, редактирование с экранами полей и обрезкой фото.
- Настройки: конфиденциальность (язык, кто что видит, блокировки), безопасность (смена кода,
  блокировка приложения, оповещения о входе, удаление аккаунта), уведомления, данные и память,
  оформление, о Kosmo.
- Уведомления о сообщениях и звонках, пока приложение свёрнуто (служба держит соединение).

Пока только на сайте: темы в группах, приглашения по ссылке, отложенные сообщения, боты,
резервная копия, вход по QR, смена почты, несколько аккаунтов.

## Проверка без телефона
- `SyncTest` — живой тест против локального сервера: регистрация, переписка двух аккаунтов
  через WebSocket, перезагрузка снимка, загрузка файла.
  `KOSMO_TEST_URL=http://127.0.0.1:4010 ./gradlew testDebugUnitTest` (сервер с `TEST_NUMBERS=1`).
- `Screens` — скриншоты экранов (Paparazzi): `./gradlew recordPaparazziDebug`,
  картинки — `app/src/test/snapshots/images/`.

## Сборка
```sh
cd android
echo "sdk.dir=/path/to/android-sdk" > local.properties
KOSMO_KEYSTORE=/path/kosmo-app.keystore KOSMO_KEYSTORE_PASSWORD=... ./gradlew assembleRelease
# другой сервер: ./gradlew assembleRelease -PkosmoUrl=https://example.org
```
Готовый APK кладётся в `web/kosmo.apk` («Профиль → О Kosmo → Download for Android»).
Ключ подписи в репозиторий не коммитится; обновление поверх установленного приложения
работает только с тем же ключом.
