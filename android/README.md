# Kosmo для Android

Нативное приложение на Kotlin + Jetpack Compose (Material 3, динамические цвета).
Интерфейс мессенджера — тот же веб-клиент из `web/`, открытый в WebView. Всё,
что выходит на сайте, сразу появляется в приложении, переустанавливать APK не нужно.

Нативная часть:
- заставка с планетой и экран «Нет связи» с кнопкой «Повторить» (Compose);
- разрешения камеры и микрофона для звонков, кружков и голосовых, геолокация;
- выбор фото, видео, музыки и файлов из галереи (несколько сразу);
- системная кнопка «Назад»: закрывает меню, листы, панели, чат (`window.kosmoBack` в `web/js/panels.js`);
- цвет статус-бара и навигации подстраивается под тему сайта;
- чужие ссылки открываются в браузере, загрузки — через системный менеджер;
- edge-to-edge и клавиатура: WebView не уходит под вырезы и панели.

Чего пока нет: push-уведомлений в фоне (WebView их не получает, нужен Firebase).

## Сборка

```sh
cd android
echo "sdk.dir=/path/to/android-sdk" > local.properties
KOSMO_KEYSTORE=/path/kosmo-app.keystore KOSMO_KEYSTORE_PASSWORD=... ./gradlew assembleRelease
# другой сервер: ./gradlew assembleRelease -PkosmoUrl=https://example.org
```

Готовый APK кладётся в `web/kosmo.apk` и скачивается с сайта: «Профиль → О Kosmo → Download for Android».
Ключ подписи в репозиторий не коммитится; обновление поверх установленного приложения
работает только с тем же ключом.
